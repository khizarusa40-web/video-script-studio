# Video Script Studio v2.0 (AI Transcript & Multi-Quality Downloader)

ایک جدید ترین ٹول جو کسی بھی ویڈیو کا **100% درست سکرپٹ (Transcript)** نکالتا ہے، ترجمہ کرتا ہے، اور ویڈیوز کو **4K، 2K، 1080p، 720p، 480p یا صرف آڈیو (MP3)** میں ڈاؤن لوڈ کرتا ہے۔

یہ ٹول **لیپ ٹاپ (Laptop)** اور **موبائل فون (Mobile)** دونوں پر بیک وقت کام کرتا ہے۔

---

## 🌟 اہم خصوصیات (Key Features):

1. **ویڈیو سے سکرپٹ نکالنا (Main Feature):**
   - Groq Whisper Large v3 کے ذریعے دنیا کا سب سے درست اور تیز ترین سکرپٹ۔
   - چینی (Chinese)، انگریزی، اردو، ہندی سمیت کسی بھی زبان کی ویڈیو سے سکرپٹ نکالے۔
   - ایک کلک میں سکرپٹ کاپی کرنے کا آپشن (`📋 سکرپٹ کاپی کریں`)۔
   - براہِ راست انگریزی یا اردو میں ترجمہ (`Translate to English / Urdu`)۔
   - ٹائم اسٹیمپ (SRT / Subtitles) اور `.txt` ڈاؤن لوڈ کرنے کا آپشن۔

2. **ویڈیو ڈاؤن لوڈنگ (Multi-Quality Video Downloader):**
   - **4K (2160p)** Ultra HD
   - **2K (1440p)** Quad HD
   - **1080p** Full HD
   - **720p** HD
   - **480p** SD
   - **MP3 / Audio Only**
   - ہائی ریزولوشن ویڈیوز کو بغیر کوالٹی کھوئے خودکار طور پر آڈیو کے ساتھ مرج (FFmpeg 7.1) کرتا ہے۔

3. **تمام پلیٹ فارمز کی سپورٹ:**
   - **YouTube** (Shorts اور لمبی ویڈیوز)
   - **TikTok**
   - **Instagram** (Reels اور ویڈیوز)
   - **Facebook**
   - **RedNote (Xiaohongshu - 小红书)**: اگر آپ چینی میں کاپی شدہ شیئر ٹیکسٹ پیسٹ کریں گے تو یہ خود بخود لنک نکال لے گا!
   - **Douyin (抖音)**, **Bilibili**, **X (Twitter)** وغیرہ۔

4. **موبائل فون اور لیپ ٹاپ دونوں پر استعمال:**
   - جب آپ لیپ ٹاپ پر ٹول چلاتے ہیں، تو اسکرین پر **QR Code** اور **موبائل لنک** ظاہر ہوتا ہے۔
   - موبائل فون سے کیو آر کوڈ اسکین کریں یا لنک کھولیں—ٹول فوراً موبائل پر چل پڑے گا۔
   - موبائل براؤزر میں **"Add to Home Screen"** دبا کر موبائل کی اسکرین پر اس کا آئیکن رکھ سکتے ہیں۔

---

## 🚀 چلانے کا طریقہ (How to Run):

### طریقہ 1 (لیپ ٹاپ پر):
1. فولڈر میں موجود `run.bat` فائل پر ڈبل کلک کریں۔
2. ٹول خود بخود آپ کے براؤزر میں `http://localhost:8741` پر کھل جائے گا۔

### طریقہ 2 (کمانڈ لائن):
```bash
python server.py
```

---

## 📱 موبائل سے کیسے کنیکٹ کریں؟
1. یقینی بنائیں کہ آپ کا لیپ ٹاپ اور موبائل ایک ہی وائی فائی (Wi-Fi) انٹرنیٹ سے کنیکٹ ہیں۔
2. ٹول کے اندر **"📱 موبائل کنیکٹ"** ٹیب پر کلک کریں۔
3. اپنے موبائل کے کیمرہ سے کیو آر کوڈ (QR Code) اسکین کریں، یا وہاں دیا گیا لوکل آئی پی لنک (مثلاً `http://192.168.1.X:8741`) اپنے موبائل کے براؤزر (Chrome یا Safari) میں کھولیں۔
4. موبائل پر ایپ کی طرح رکھنے کے لیے:
   - **Android:** Chrome مینیو (3 ڈاٹس) &rarr; **Add to Home screen**.
   - **iPhone:** Safari نیچے شیئر بٹن &rarr; **Add to Home Screen**.

## 🔑 Groq API Key (100% مفت):
1. [console.groq.com/keys](https://console.groq.com/keys) کھولیں۔
2. فری اکاؤنٹ لاگ ان کریں اور **Create API Key** پر کلک کریں۔
3. کی کو کاپی کر کے ٹول کی **سیٹنگز (Settings)** میں پیسٹ کر کے **ٹیسٹ و سیو** دبا دیں۔ یہ کی صرف ایک بار ڈالنی ہوگی اور مستقل محفوظ رہے گی۔
